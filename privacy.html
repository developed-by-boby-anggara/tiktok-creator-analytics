Privacy Policy

Last updated: November 2026

1. Information We Collect

Creator Analytics Studio accesses authorized TikTok account metrics strictly through the official TikTok Display API upon explicit user consent via OAuth 2.0. This includes basic profile details (display name, avatar), account statistics (follower count, likes count), and public video performance metrics (views, likes, comments, shares).

2. How We Use Information

The retrieved data is used exclusively to display personal content performance analytics, calculate engagement rates, identify optimal posting schedules, and generate automated content improvement recommendations for the authenticated creator.

3. Data Storage and Security

We do not sell, rent, or distribute user data to third parties. Authentication tokens and analytical metrics are stored securely within the user's private browser session and authorized Firebase database instance. Users may revoke access at any time via their TikTok account security settings.

4. Contact Information

For questions regarding this Privacy Policy or data removal requests, please contact the developer via the associated GitHub repository.
